# Semiannual Capacity Planning for a Hospital Endoscopy Unit

Full **MILP** formulation planning 26 weeks of capacity across 10 procedure rooms in a GI unit — balancing setup costs, allocation costs, demand satisfaction, and clinician utilisation. Solved in R and translated into a plain-English managerial statement.

**Tools:** R, MILP · **Outcome:** cost-optimal room configuration meeting patient demand
