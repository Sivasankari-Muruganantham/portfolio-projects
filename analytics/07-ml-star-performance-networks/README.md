# Predicting Star Performance in Collaboration Networks

What makes a star performer emerge from professional collaboration networks? Compared linear, polynomial, LASSO, and classification models — then extended the analysis with ten original investigations including career-stage analysis, engineered features, threshold optimisation, and misclassified-case profiling.

**Tools:** R · **Methods:** LASSO, logistic regression, LDA, interaction effects · **Outcome:** four evidence-based pathways to star emergence
